# 🎬 مولد يوتيوب شورتس عربي مجاني (GitHub Actions)

يعمل على **GitHub Actions** مجانًا ويولد فيديوهات عمودية (9:16) جاهزة للرفع على يوتيوب شورتس.

## المميزات
- لغة عربية (صوت edge-tts عالي الجودة)
- **Captions عربية محروقة** على الفيديو (حجم كبير ومناسب للشورتس)
- أنت تكتب العناوين فقط → السكريبت يتولد تلقائيًا
- فيديو عمودي 1080×1920
- تشغيل يدوي أو أسبوعي تلقائي (3 فيديوهات على الأقل)
- مجاني 100% (Gemini + Pexels + edge-tts + GitHub Actions)

## الإعداد السريع (5 دقائق)

### 1. اعمل Repository جديد على GitHub
ارفع كل الملفات دي في ريبو جديد (يفضل Public عشان الدقايق المجانية أكتر).

### 2. أضف الـ Secrets
روح على: **Settings → Secrets and variables → Actions → New repository secret**

| الاسم              | منين تاخده                              | مطلوب؟ |
|--------------------|-----------------------------------------|--------|
| `GEMINI_API_KEY`   | [Google AI Studio](https://aistudio.google.com/app/apikey) | نعم (مستحسن) |
| `PEXELS_API_KEY`   | [Pexels API](https://www.pexels.com/api/) | مستحسن |

> لو مفيش Gemini هيستخدم سكريبت بسيط. لو مفيش Pexels هيستخدم خلفيات لونية.

### 3. أضف عناوينك
افتح ملف `topics/topics.txt` واكتب عنوان واحد في كل سطر:

```
كيف تزيد إنتاجيتك في العمل
أسرار النوم العميق
أفضل 5 عادات صباحية ناجحة
```

### 4. شغّل الـ Workflow
1. روح على تبويب **Actions**
2. اختار **توليد يوتيوب شورتس عربي**
3. اضغط **Run workflow**
4. اختار عدد الفيديوهات (1–5)
5. انتظر 5–15 دقيقة

### 5. نزّل الفيديوهات
بعد ما يخلص الـ run:
- ادخل على الـ run
- في الأسفل هتلاقي **Artifacts**
- نزّل الملف المضغوط → فيه ملفات `.mp4` جاهزة

## الصوت العربي المتاح

## التشغيل التلقائي الأسبوعي
الـ workflow مضبوط يشتغل **كل يوم اثنين الساعة 9 صباحًا UTC**.  
تقدر تعدل السطر ده في الملف `.github/workflows/generate-shorts.yml`:

```yaml
- cron: "0 9 * * 1"   # كل اثنين
```

## هيكل المشروع
```
├── .github/workflows/generate-shorts.yml
├── scripts/generate_shorts.py
├── topics/
│   ├── topics.txt          ← العناوين الجديدة
│   └── done.txt            ← العناوين اللي اتولدت
├── output/                 ← الفيديوهات (بتتعمل أثناء التشغيل)
├── requirements.txt
└── README.md
```

## ملاحظات مهمة
- كل فيديو بياخد تقريبًا 3–6 دقايق على الـ runner.
- الـ Artifacts بتفضل 14 يوم، نزّلها بسرعة.
- لو عايز جودة أعلى، زوّد عدد الصور أو غيّر الـ CRF في السكريبت.
- الـ quota المجاني لـ Gemini وPexels كافي لـ 3–5 فيديوهات أسبوعيًا بسهولة.
