# 🎬 مولد يوتيوب شورتس عربي مجاني (GitHub Actions)

يعمل على **GitHub Actions** مجانًا ويولد فيديوهات عمودية (9:16) جاهزة للرفع على يوتيوب شورتس.

## المميزات
- لغة عربية (صوت edge-tts عالي الجودة)
- **Captions عربية محروقة** على الفيديو
- **ترجمة تلقائية** للكلمات المفتاحية → صور أدق من Pexels
- **Thumbnail تلقائي** لكل فيديو
- أنت تكتب العناوين فقط → السكريبت يتولد تلقائيًا
- فيديو عمودي 1080×1920
- **تشغيل يدوي فقط** (مفيش جدولة تلقائية)
- مجاني 100%

## الإعداد السريع

### 1. اعمل Repository جديد على GitHub
ارفع كل الملفات دي في ريبو جديد (يفضل Public).

### 2. أضف الـ Secrets
**Settings → Secrets and variables → Actions → New repository secret**

| الاسم              | منين تاخده                                      | مطلوب؟ |
|--------------------|--------------------------------------------------|--------|
| `GEMINI_API_KEY`   | [Google AI Studio](https://aistudio.google.com/app/apikey) | مستحسن جدًا |
| `PEXELS_API_KEY`   | [Pexels API](https://www.pexels.com/api/)        | مستحسن |

### 3. أضف عناوينك
افتح `topics/topics.txt` واكتب عنوان واحد في كل سطر:

```
كيف تزيد إنتاجيتك في العمل
أسرار النوم العميق
أفضل 5 عادات صباحية ناجحة
```

### 4. شغّل يدويًا
1. تبويب **Actions**
2. اختار **توليد يوتيوب شورتس عربي**
3. **Run workflow** → اختار عدد الفيديوهات
4. انتظر 5–15 دقيقة

### 5. نزّل النتائج
من الـ **Artifacts** هتلاقي:
- ملفات `.mp4` (الفيديوهات)
- ملفات `_thumb.jpg` (الصور المصغرة)
- ملفات `.json` (السكريبت والمعلومات)
